🐛 TROUBLESHOOTING

Problem: "Address already in use"
  → Port 8080 is being used
  → Change PORT in RestServer.java to 9000
  → Or kill the process using port 8080

Problem: "index.html not found" (404 error)
  → Make sure index.html is in project root
  → Not in src/ folder!
  → Level where README.md is

Problem: Menu not loading
  → Check browser console (F12)
  → Ensure server is running (should see startup message)
  → Try refreshing the page (Ctrl+Shift+R)

Problem: Orders not submitting
  → Check browser console for error messages
  → Verify CORS headers are being sent
  → RestServer.java should add them automatically
